# Situational Profile Questions

Check whether `situational-profile.md` exists in the workspace.

If it exists, read it. Reuse it only when it clearly belongs to the same candidate and answers all required questions below. Ask only for missing or materially ambiguous answers. Never silently reuse another candidate's situational profile.

If a new or updated profile is required, ask:

1. What is your current location?
2. What is your citizenship?
3. Is there any known immigration restriction, visa complexity, or employer sponsorship issue specifically tied to your citizenship? Use concrete facts if known; do not use passport rankings or perceived nationality prestige. ("none known" is acceptable.)
4. What language(s) do you speak?
5. What language do you require for your work environment?
6. What is your minimum acceptable monthly salary, and in what currency? Is it a hard floor or historical/context-only information? ("not specified" is acceptable.)
7. Are you already living in, or do you have existing work authorization for, any target country? State the country and whether the authorization is independent or still requires employer sponsorship. ("not applicable" is acceptable.)
8. What is your date of birth or current age? Some visa salary thresholds vary by age. ("prefer not to say" is acceptable, but age-dependent thresholds must then be marked unresolved.)
9. What employment basis should Salary Calculator use?
   - local employment with relocation,
   - cross-border remote work from the current location, or
   - the primary path already selected by Country Finder for each country.

Explain that Salary Calculator returns one target per country, so it cannot blend local-relocation pay and cross-border remote pay into the same number.

Save the confirmed answers to `situational-profile.md`, including the candidate's name or another clear identity key from `profile.md`.
