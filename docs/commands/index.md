# Commands

Guides to using Agent Compass for your job search. Each command page explains how to start, what happens along the way and what results to expect.

All four commands share one question mechanism (QM). It chooses a native question control when your client supports the required choice, text input or review. If that presentation is unavailable, it tries a supported form of the same decision before using conversation. A confirmed rendering failure follows the same ordered alternatives after the old request is closed. Choices, required answers and approvals stay the same; an unanswered or cancelled prompt never counts as consent. Resumes and research can still be supplied through normal chat, pasted text or readable local files.
