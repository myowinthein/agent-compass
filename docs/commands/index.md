# Commands

Claude Compass provides four slash commands. Country Finder, Salary Calculator, and Job Screener require a resume — on first run, Claude prompts you to upload one and extracts it to `profile.md` in your workspace. Country Finder and Salary Calculator are multi-step pipelines that resume from where they left off if interrupted. Portal Finder (which needs only a country) and Job Screener (which reuses your saved profile) each run in a single step with no state to resume.
