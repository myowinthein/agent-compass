# Step 5: Final verification

Independently audits the salary framework before presenting it.

## Checks

The audit verifies:

1. Candidate role and level
2. Source integrity and evidence grade
3. Recruiter-attraction adjustment and 12 percent cap
4. Deterministic calculations and currency-aware rounding
5. Visa route, applicability, threshold basis, date, and official source

A fresh web check is used when decisive evidence is stale, inaccessible, contradictory, weak, or produces an outlier.

## Corrections

A value changes only because of:

- a verified source,
- a role, level, unit, currency, or compensation-basis correction,
- a deterministic arithmetic error,
- a visa-threshold applicability correction.

The auditor does not lower salaries based only on intuition or generic recruiter language. If evidence remains too weak, the country is withheld rather than assigned an invented number.

## Output

The full audit and final table are saved together in `sc-step5b-final-verification.md`. Chat shows only the compact final table and one completion sentence.
