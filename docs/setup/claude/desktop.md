# Claude desktop app

Read the [Setup notes]({{ '/docs/setup/' | relative_url }}) before starting.

## Install

1. Open **Customize → Plugins** in Claude Desktop.
2. Choose **Add plugin → Add marketplace → Add from a repository**.
3. Enter `myowinthein/agent-compass`, select the repository or **Use “myowinthein/agent-compass”**, then click **Sync**.
4. Find **Agent Compass** in the marketplace and click **Add**.
5. Open **Yours** and check that the plugin is enabled and lists all four skills.
6. Start a fresh chat in your job search workspace. Type `/` and filter by `country`, `portal`, `salary`, or `job` to find the workflows.

## Update

1. Open **Customize → Plugins → Yours**.
2. Open Compass's **More actions** menu and choose **Check for updates**.
3. If offered, open the plugin and click **Update**. Check its version, then start a fresh chat.

## Uninstall

1. Open **Customize → Plugins → Yours**.
2. Open Compass's **More actions** menu, choose **Remove**, then confirm **Remove**.
3. Check that the card is gone from **Yours** and the workflows are absent from a fresh chat.
