# Codex desktop app

Read the [Setup notes]({{ '/docs/setup/' | relative_url }}) before starting.

## Install

1. Open the sidebar **Plugins** icon to reach **Customize → Plugins**.
2. Choose **Add → Add a marketplace**. Enter `myowinthein/agent-compass` in **Source**, then click **Add marketplace**.
3. Select **Personal** and find the Compass marketplace. Click **+** beside Compass to install it. It may appear as `agent-compass` or **Agent Compass**.
4. Open Compass under **Installed**. Check its **Version** and that all four skills are enabled.
5. Start a fresh chat in your job search workspace. Type `$` and filter by `country`, `portal`, `salary`, or `job` to find the workflows.

## Update

1. Open **Settings → Integrations → Plugins → Marketplace**.
2. Find the Compass marketplace and click **Upgrade**.
3. Reopen the plugin details and check its version and enabled skills.
4. Start a fresh chat to check workflow availability.

## Uninstall

1. Open **Customize → Plugins → Personal**.
2. Open Compass's **…** menu and choose **Uninstall**.
3. Check that Compass is gone from **Installed** and its workflows are absent from a fresh chat's `$` picker.
