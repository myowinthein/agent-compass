## Claude-specific contributor rules

For repository maintenance in Claude, also read the installed claude-helm rules:

- ~/.claude/plugins/marketplaces/claude-helm/rules/git.md
- ~/.claude/plugins/marketplaces/claude-helm/rules/safety.md

If either file is missing, report that claude-helm is not installed. These optional contributor rules are not a dependency of the Compass workflows.
